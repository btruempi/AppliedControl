    About This Textbook

    Applied Control Valve Automation Mastery

    This is an intelligent textbook for sales engineers, application engineers, and technical specialists at Applied Control — an Emerson Impact Partner specializing in valve automation, process measurement, and distributed control systems.

    Why This Textbook Exists

    A new sales engineer at Applied Control faces a portfolio spanning control valves, actuators, positioners, distributed control systems, safety systems, flow measurement, level measurement, and asset management — all applied across oil and gas, refining, power, chemical, life sciences, and water treatment.

    Existing training resources are either too shallow (marketing brochures), too broad (Emerson's global catalog), or too specific (individual product datasheets). None of them provide the integrated understanding needed to walk into a customer conversation and connect the physics of cavitation to the specification of a Fisher Cavitrol III trim, or to connect a plant manager's concern about unplanned downtime to the ROI of a DVC6200 positioner upgrade.

    This textbook was built to fill that gap.

    The McCreary Intelligent Textbook Methodology

    This textbook is built following Dan McCreary's intelligent textbook methodology, which defines five levels of textbook sophistication:

    Level Description
    0 Static print
    1 Digital static (PDF)
    2 Interactive: MicroSims, search, learning graph ✓
    2.9 AI-grounded content, concept prerequisites ✓
    3–5 Fully adaptive, personalized tutoring

    The Applied Control Mastery textbook is built at Level 2.9. The core data structure is a learning graph — a directed acyclic graph of 490 concepts connected by 788 prerequisite edges. The graph organizes all knowledge in this domain into a navigable structure showing exactly what you need to know before you can understand each new concept.

    Learning Graph Features

    • 490 concepts across 12 taxonomy categories
    • 788 dependency edges — prerequisite relationships between concepts
    • Concept Impact Score (CIS) — a PageRank-style measure of how foundational each concept is. High-CIS concepts are taught first because mastering them unlocks the most downstream knowledge
    • Interactive Graph Explorer — searchable, filterable visualization of the complete concept graph. Click any node to see its prerequisites and what it unlocks

    MicroSims

    Each major chapter includes at least one MicroSim — a self-contained interactive simulation that lets the learner experience the concepts rather than just reading about them:

    Sim Chapter What you learn
    PID Loop Animator Chapter 1 How P, I, D gains affect process response — oscillation, sluggish, well-tuned
    Cavitation Visualizer Chapter 2 How upstream/downstream pressure and vapor pressure interact to cause cavitation or flashing
    Globe Valve Cross-Section Chapter 4 How plug position, cage port area, and flow characteristic combine to determine flow
    Flow Characteristics Chapter 5 How equal-%, linear, and quick-opening characteristics behave, and how valve authority distorts the installed curve

    MicroSims are self-contained HTML files using only native browser APIs (no server required). They work offline in any modern browser.

    Technical Notes

    This textbook is built with:

    • MkDocs with the Material for MkDocs theme
    • IBM Plex Sans and IBM Plex Mono typefaces (Google Fonts)
    • vis-network (v9.1.9) for the interactive knowledge graph explorer
    • Native Canvas 2D API for all MicroSims (no external libraries required)
    • Learning graph generated by a Python script implementing Kahn's topological sort and recursive CIS calculation

    The learning graph JSON (learning-graph.json) is the textbook's primary data structure. It can be used independently of the textbook for learning path recommendation, concept search, and prerequisite analysis.
