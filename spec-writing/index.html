    Specification Writing Guide

    Write Specs That Win Business

    The Applied Control guide to writing Fisher valve and Rosemount instrument specifications — from datasheet to delivered equipment

    Why Specification Writing Matters for Sales Engineers

    When you write the specification, you define the technical requirements. When you define the requirements, the products you specify win the bid — because the spec reflects what Fisher, Rosemount, and DeltaV equipment actually delivers. This guide teaches you to write accurate, defensible specifications that protect the customer and position Applied Control equipment.

    Part 1: Understanding the Specification Process

    What a Spec Actually Does

    A control valve or instrument specification is a technical document that defines exactly what equipment must be provided. It tells the customer's engineering team, procurement, and eventual contractor:

    1. What the process conditions are (fluid, pressure, temperature, flow range)
    2. What the equipment must do (control, measure, isolate, relieve)
    3. What standards apply (ASME, API, IEC, ISA)
    4. What manufacturer and model is required (or "approved equal" language)

    Specifications are written at three points in a project:

    Phase Document Purpose
    Front-end engineering (FEED) Valve List / Instrument Index Scope definition; budget
    Detailed engineering Valve Datasheet / Instrument Datasheet Procurement document
    Construction/commissioning Loop diagram + instrument spec Installation and calibration

    Who Writes the Spec?

    In an ideal world, the EPC contractor's instrument engineer writes the specification. In the real world: - Many plants ask Applied Control to write preliminary specs during pre-FEED - Specification writing is a way for Applied Control to be designed in from the start - A customer who can't afford a full-time instrument engineer often relies on their supplier to spec equipment correctly

    Applied Control's ability to write accurate datasheets — not just quote from a catalog — is a key differentiator.

    Part 2: Fisher Control Valve Datasheets (IEC 60534)

    The IEC 60534 Datasheet Structure

    The international standard for control valve data is IEC 60534, and the Fisher datasheet format follows it closely. Here's every field and what it means.

    Section A — Process Data (What the valve must handle)

    Field What to fill in Source
    Fluid Exact process fluid name and phase (e.g., "Crude oil, liquid") Process engineer / P&ID
    Fluid state Liquid, gas, steam, two-phase Process engineer
    Operating pressure P1 Normal upstream pressure (PSIG or bar) Process datasheet
    Operating pressure P2 Normal downstream pressure Process datasheet
    Shutoff pressure differential Maximum ΔP valve must hold closed (worst-case) Process engineer
    Maximum ΔP at normal flow P1 − P2 at normal operating conditions P1 − P2 from above
    Normal flow rate Design flow at normal conditions (GPM, SCFM, lb/hr) Process flow sheet
    Maximum flow rate Maximum expected flow (typically 110–130% of normal) Process engineer
    Minimum flow rate Minimum controllable flow (determines rangeability) Process engineer
    Operating temperature Normal fluid temperature at valve inlet (°F or °C) Process datasheet
    Maximum temperature Highest possible process temperature Upset conditions
    Viscosity For liquids: centistokes at operating temp Fluid properties
    Specific gravity (liquid) Liquid SG relative to water at operating temp Fluid properties
    Molecular weight (gas) For gases and steam Fluid properties
    Vapor pressure Pv Liquid vapor pressure at operating temp Fluid properties (for cavitation check)
    Critical pressure Pc Fluid critical pressure Fluid properties

    Plain English

    If you don't have the fluid properties, Emerson's sizing software (Emerson Valve Sizing) has built-in property databases for hundreds of common fluids. For unusual fluids, the process engineer's process simulation (Aspen, HYSYS) is the source.

    Section B — Valve Sizing Results

    Once process data is complete, run Emerson sizing software or ISA 75.01 equations to determine:

    Field Description
    Calculated Cv Flow coefficient at maximum flow; valve must be ≥ this
    Required Cv at normal flow Cv at normal conditions — determines operating point
    Valve travel at normal flow Target: 50–70% for good control (not 95%, not 15%)
    Cavitation check (Fl × P1) Compares P1 to critical cavitation pressure; flags if cavitation is possible
    Noise prediction dBA at 1m; flag if > 85 dBA for trim selection
    Velocity check Stream velocity through trim; flag if > 50 fps for erosion potential

    Field Story

    A refinery engineer asked Applied Control to size a new feedwater heater level valve for 2" line service. Initial sizing showed the Cv requirement was 0.42 at normal flow with a maximum Cv of 1.1. The Fisher EZ body (1" body, Cv 3.0 in the smallest trim) would operate at about 15% open at normal flow — way too low for stable control. Applied Control recommended a Fisher ED 1" body with smaller trim (Cv 1.5) to place normal operation near 55% open. This is the kind of judgment that prevents a bad installation — and it's only possible if the sales engineer understands sizing.

    Section C — Valve Body Data

    Field How to fill it in
    Manufacturer Fisher Controls (specify; "approved equal" only if required)
    Model ED (globe, standard), EZ (globe, small), HP (high-pressure/forged), GX (next-gen globe), V150/V250/V300 (rotary Vee-Ball), D3 (lined butterfly), ES (triple-offset butterfly)
    Body size Pipe size (e.g., 2" or 50mm) — note: body size may differ from line size with reducers
    Pressure class ANSI Class 150, 300, 600, 900, 1500, or 2500; API 3000/5000/10000 for choke
    End connections Flanged (ASME B16.5), butt-weld, socket-weld
    Body material WCB (carbon steel, –20°F to +800°F), CF8M (316 SST, corrosive), LCC (low-carbon, cold service), WC9 (Cr-Mo, high temperature), CF3M (low-carbon 316L, pharma/cryogenic)
    Flow direction Flow-to-open (FTO, most common) or flow-to-close (FTC, for noise/cavitation)

    Body selection by application:

    Application Recommended body
    General liquid/gas, < 600 class Fisher ED Globe
    Small flows, < 2" line, Cv < 5 Fisher EZ Globe
    High pressure, > 900 class, offshore, hydrogen Fisher HP (forged body)
    Next-gen with integral DVC mount Fisher GX Globe
    Rotary, large Cv, throttling Fisher V250 Vee-Ball
    Large butterfly, water/HVAC Fisher V150/V200
    Lined butterfly, corrosive Fisher D3 with PTFE liner
    High-temperature, triple-offset Fisher ES

    Section D — Trim Data

    Field Options
    Trim type Standard (equal %, linear, quick-open) — see below
    Trim material 316 SST (standard), Alloy 6 (erosion), Alloy 20 (acid), ceramic (severe erosion)
    Leakage class Class IV (0.01% Cv, standard), Class V (5×10⁻⁴% Cv, metal seat, higher ΔP), Class VI (< bubble leak, soft seat, shutoff)
    Pressure balanced Yes/no — balanced trim for high ΔP to reduce actuator thrust
    Special trim WhisperFlo (noise), Cavitrol III (cavitation), Lo-dB (gas noise)

    Flow characteristic selection:

    Characteristic When to specify
    Equal percentage Most process control loops (flow, pressure, level with varying ΔP)
    Linear Level control, mixing loops, constant ΔP systems
    Quick-opening On/off service; safety block valves

    Equal % is usually right

    Equal percentage is the default for most throttling service. It compensates for the naturally nonlinear relationship between valve position and flow — so PID loop gain stays more consistent across the operating range.

    Section E — Actuator Data

    Field Specification
    Actuator type Diaphragm (spring-return) or piston
    Model Fisher 657 (spring-to-open) or 667 (spring-to-close)
    Spring range 3–15 PSIG (standard control range) or 6–30 PSIG (high-differential trim)
    Fail action Fail-open (657) or fail-closed (667)
    Actuator size From sizing calculation (ensure thrust exceeds required at all conditions)
    Handwheel Manual handwheel for field override? Yes/No

    Section F — Positioner Data

    Field Specification
    Positioner Fisher FIELDVUE DVC6200 (standard); DVC6200 SIS (safety application)
    Input signal 4–20 mA HART
    Action Direct (increasing signal = increasing travel) or reverse
    Split range Single full range (standard) or half-range (split-range control pairs)
    Diagnostics Enable friction trending, travel deviation alerts, valve signature capability
    Communication HART Revision 7

    Section G — Accessories and Options

    Accessory When to specify
    Volume booster Fast-stroking loops (anti-surge, ESD); stroke time < 2 seconds required
    Solenoid valve (ASCO) SIS/ESD application; air supply isolation
    Limit switches Position feedback (open/closed discrete) to DCS
    Position transmitter (4–20 mA) Continuous position feedback to DCS or AMS
    Supply pressure regulator When instrument air supply is not clean/regulated to 20 PSIG
    Cryogenic extension bonnet For service below –50°F (–46°C)
    High-temperature packing Graphite packing for > 450°F service
    Bellows seal Zero-emission service (LDAR compliance, toxic fluids)
    Low-emission packing ANSI/FCI 70-2 Class VI or TA-Luft compliant packing

    Part 3: Sample Completed Control Valve Datasheets

    Example 1: Crude Oil Flow Control Valve (Refinery)

    Process: Crude preheat train, atmospheric distillation unit. Controls crude oil flow to the preflash drum.

    Field Value
    Fluid Crude oil (liquid, SG 0.87)
    Operating P1/P2 215 PSIG / 60 PSIG
    Shutoff ΔP 215 PSIG
    Normal flow 850 GPM
    Maximum flow 1,100 GPM
    Min flow 150 GPM
    Temperature 185°F normal, 260°F max
    Vapor pressure 8.2 PSIA at 185°F
    Calculated Cv (max) 147
    Body Fisher ED, 4", Class 300
    Body material WCB carbon steel
    Trim type Equal percentage, 316 SST, Class V shutoff
    Positioner DVC6200, 4–20 mA HART, fail-closed (667)
    Accessories Volume booster (fast response), limit switches

    Cavitation check: FL² × (P1 − Pv) = 0.68² × (215 − 8.2) = 95.6 PSIG; Required ΔP = 155 PSIG > 95.6 → Cavitation risk: low. Standard trim is acceptable.

    Example 2: Boiler Feedwater Level Control Valve (Power Plant)

    Process: Drum boiler feedwater level control — controls flow of high-pressure boiler feedwater from deaerator to steam drum.

    Field Value
    Fluid Boiler feedwater (liquid, SG 0.92 at 280°F)
    Operating P1/P2 1,440 PSIG / 1,050 PSIG
    Shutoff ΔP 1,440 PSIG
    Normal flow 95,000 lb/hr
    Temperature 280°F normal
    Vapor pressure 49 PSIA at 280°F
    Body Fisher HP, 2", Class 1500
    Body material A105 forged carbon steel
    Trim Equal %, Alloy 6 (erosion-resistant), Class V
    Actuator Fisher 667, spring-to-close (fail closed)
    Positioner DVC6200 SIS (level is a SIS function in some configurations)

    Why Fisher HP? The combination of 1,440 PSIG shutoff ΔP and 280°F service requires a forged body (not cast), Class 1500 flanges, and robust trim. The Fisher HP is designed for this — the catalog globe bodies (ED, EZ) top out at Class 600.

    Example 3: Bioreactor pH Control Valve (Pharmaceutical)

    Process: Acid addition to bioreactor for pH control. Fluid is 38% sulfuric acid.

    Field Value
    Fluid 38% H₂SO₄ (liquid)
    Operating P1/P2 30 PSIG / 14.7 PSIG
    Normal flow 0.5 GPH
    Temperature Ambient (70°F)
    Body Fisher EZ, 1", Class 150
    Body material CF3M (316L SST)
    Trim Equal %, Alloy 20 (acid service), Class VI (sanitary shutoff)
    End connections Tri-clamp sanitary ends
    Actuator Fisher 667, spring-to-close
    Positioner DVC6200, FOUNDATION Fieldbus (preferred for pharma batch systems)
    Documentation IQ/OQ documentation package

    Alloy 20 trim: Carpenter Alloy 20 (UNS N08020) is highly resistant to sulfuric acid — the standard 316 SST trim would corrode rapidly in 38% H₂SO₄.

    Example 4: Gas Pressure Control Valve (High-Pressure Natural Gas)

    Process: Natural gas letdown from 900 PSIG sales header to 300 PSIG plant distribution. High noise potential.

    Field Value
    Fluid Natural gas (vapor), SG 0.62, MW 17.2
    Operating P1/P2 900 PSIG / 300 PSIG
    Normal flow 12 MMSCFD
    Maximum flow 18 MMSCFD
    Temperature 50°F (Joule-Thomson cooling at letdown)
    Calculated Cv 85 at max flow
    Body Fisher HP, 4", Class 900
    Trim Whisper III lo-dB trim (high ΔP gas noise control)
    Body material A350-LF2 (low-temperature carbon steel, –50°F rating)
    Actuator Fisher 667, spring-to-close (fail-closed on gas supply)
    Positioner DVC6200
    Accessories ASCO solenoid (ESD isolation)

    Noise calculation: For this service, predicted noise without special trim ≈ 97 dBA at 1m — well above the 85 dBA limit for occupied areas. WhisperFlo trim uses multiple-stage pressure drop with labyrinthine flow paths to reduce noise by 15–20 dBA. Required.

    Part 4: Rosemount Instrument Datasheets

    Pressure Transmitter Datasheet (Rosemount 3051)

    Field Description
    Application Flow (DP across orifice), pressure, level (DP or gauge)
    Measured variable Differential pressure, gauge pressure, absolute pressure
    Range Calibrated span; 3051 ranges from 0–0.1" H₂O to 0–2000 PSIG
    Upper range limit (URL) Maximum measurable pressure
    Accuracy ±0.04% of span (3051C reference accuracy)
    Process connection ¼" NPT, ½" NPT, or manifold
    Wetted materials 316 SST standard; Hastelloy C for corrosive; PVDF for HF acid
    Fill fluid Silicone (standard, –40°F to +185°F); inert fluorocarbon (cryogenic, food)
    Process temperature Min/max fluid temperature at sensing diaphragm
    Ambient temperature Min/max ambient at transmitter electronics
    Output 4–20 mA HART (standard); FOUNDATION Fieldbus; Wireless
    Power supply 10.5–42.4V DC for HART; 9–32V DC for Fieldbus
    Enclosure NEMA 4X/IP66 standard
    Approvals FM/CSA Explosionproof Class I Div 1; ATEX II 1G
    Mounting Direct mount (impulse piping), manifold mount, or remote seal

    Remote seal selection (for level/plugging service):

    Service Remote seal recommendation
    Viscous or plugging fluid Flush diaphragm (flat face), 3051 + direct-mount seal
    High temperature fluid Capillary remote seal, 5–15 ft capillary
    Cryogenic service Extended cooling diaphragm with inert fill fluid
    Sanitary/hygienic Sanitary flush seal, tri-clamp process connection

    Flow Transmitter Datasheets

    Rosemount 3051SFP Annubar (DP Flow)

    Field Specification
    Measurement principle Averaging Pitot tube (multiport) with DP transmitter
    Pipe sizes 2"–96"
    Accuracy ±0.75% of rate (standard); ±0.5% with calibration
    Applications Water, wastewater, steam, clean gas — large diameter, low cost
    Beta ratio Precalculated; no bore calculation needed (unlike orifice plate)
    Output 4–20 mA HART with integral 3051 transmitter
    Installation Insertion into pipe; no process shutdown for removal

    Rosemount 8800D Vortex

    Field Specification
    Measurement principle Vortex shedding; frequency proportional to velocity
    Pipe sizes ½"–16"
    Accuracy ±0.65% of rate (liquid); ±1.0% (gas and steam)
    Applications Steam, saturated or superheated; clean liquids; clean gas
    No-moving-parts Extremely reliable; no drift; no zeroing required
    Output 4–20 mA HART with built-in temperature/pressure compensation
    Avoid when Highly viscous fluids (< 10,000 Re); two-phase flow; dirty fluids

    Micro Motion ELITE CMF (Coriolis)

    Field Specification
    Measurement principle Coriolis; measures mass flow directly (no density compensation)
    Line sizes ½"–12" (CMF025 to CMF400)
    Mass flow accuracy ±0.05% of rate (±0.02% for R-Series)
    Density accuracy ±0.0002 g/cm³
    Temperature accuracy ±1°C
    Applications Custody transfer, blending, batch weighing, high-value products
    Outputs 4–20 mA, frequency, HART, FOUNDATION Fieldbus, Modbus
    Process temp –240°C to +204°C
    Process pressure Up to 6,092 PSIG (depending on tube size)

    Part 5: Writing Specifications That Win Bids

    The "Lock-In" Techniques (Used Ethically)

    When Applied Control writes a spec, the goal is to specify what the customer actually needs — and if that happens to match Fisher/Rosemount/DeltaV precisely, that's because those products genuinely meet the requirements. Ethical specification writing does not invent requirements to exclude competitors — it accurately describes what the application demands:

    1. Specify the Fisher model by name when it's clearly the best choice. "Fisher ED Globe Valve or approved equal" with full technical requirements (forged body for Class 900+, Cavitrol III trim for cavitation service, DVC6200 with friction trending) ensures that any "approved equal" must actually be equal — which few competitors can match on severe service.

    2. Specify HART Revision 7 and friction trending as requirements. Many competitors only support HART Revision 5 or lack friction trending entirely. This is a legitimate technical requirement if the plant has AMS Device Manager.

    3. Specify IQ/OQ documentation per FDA 21 CFR Part 11 for pharma. Applied Control provides this; most catalog distributors don't.

    4. Specify National Board Certification for PRV test and repair. This is a legitimate regulatory requirement for OSHA PSM facilities — not invented. Applied Control has it; many shops don't.

    5. Specify Emerson Impact Partner for technical support. This is a contractual distinction — Impact Partners have access to factory technical support and expedited product availability that independent distributors do not.

    The Specification Review Meeting

    When a customer has a valve or instrument specification already written, Applied Control can offer a free specification review:

    • Review the valve datasheets against the process conditions (sizing check)
    • Identify any errors (wrong body material, undersized trim, missing accessories)
    • Identify opportunities to improve (cavitation check, noise calculation, upgrade to DVC6200)
    • Return the corrected/improved datasheets to the customer

    This positions Applied Control as the engineering resource, not just a quotation source. The customer who lets Applied Control review specs is much more likely to specify Fisher/Rosemount when they write or update those specs.

    Part 6: Specification Checklist

    Fisher Control Valve Specification Checklist

    • Fluid identified (name, phase, SG or MW, Pv, Pc)
    • P1 and P2 at normal and maximum flow conditions
    • Maximum shutoff ΔP
    • Flow rates: normal, minimum, maximum
    • Temperature: normal, maximum, minimum (cryogenic?)
    • Sizing run in Emerson ValveLink or equivalent — Cv, travel %, cavitation check, noise
    • Body model selected (ED, EZ, HP, GX, V-Ball, butterfly)
    • Body size confirmed (not just line size — check reducers)
    • Pressure class confirmed (ANSI Class matching P1 maximum)
    • Body material confirmed (WCB, CF8M, LCC, forged for Class 900+)
    • Trim type (equal %, linear, quick-open)
    • Trim material (SST standard, Alloy 6/20/Hastelloy for corrosive)
    • Leakage class (IV, V, VI per application)
    • Special trim (WhisperFlo, Cavitrol, Lo-dB) — required?
    • Fail action confirmed (fail-open or fail-closed)
    • Actuator model (657 or 667)
    • Actuator sizing confirmed (thrust ≥ required at all conditions)
    • DVC6200 positioner specified (or DVC6200 SIS for safety application)
    • ASCO solenoid for ESD/SIS application
    • Low-emission packing — required (LDAR, API 624)?
    • Cryogenic bonnet — required (< –50°F)?
    • IQ/OQ documentation — required (pharmaceutical)?
    • PRV sizing and National Board certification — coordinated?

    Rosemount Instrument Specification Checklist

    • Measurement variable defined (pressure, DP, temperature, level, flow, analysis)
    • Process fluid identified (for wetted material selection)
    • Process pressure range (select transmitter range)
    • Process temperature (transmitter range, fill fluid selection)
    • Accuracy requirement stated
    • Output protocol specified (HART, FF, wireless, 4–20 mA)
    • Hazardous area classification (FM/CSA Class I Div 1 or ATEX)
    • Enclosure rating (NEMA 4X or IP66/67)
    • Mounting method (direct mount, remote seal, flanged, insertion)
    • Wetted materials confirmed (SST, Hastelloy, PVDF for corrosive)
    • Remote seal required? (viscous, plugging, high-temperature, sanitary service)
    • Coriolis required for custody transfer or high-accuracy blending?
    • WirelessHART — gateway capacity checked for existing network?

    About This Guide

    This specification guide reflects Applied Control's engineering practice for Fisher, Rosemount, and Micro Motion products. All sizing must be confirmed with Emerson's current sizing software (ValveLink, Emerson Valve Sizing, FlowExpert) against the actual process data. This guide does not replace qualified engineering review for safety-critical applications including SIS valves, PRVs, and cryogenic service.
